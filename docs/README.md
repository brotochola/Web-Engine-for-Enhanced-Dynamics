# WeedJS documentation

Two folders. They are not the same audience.

| Folder | Who it is for |
| --- | --- |
| [`guide/`](./guide/README.md) | Someone building a game on WeedJS. Scenes, entities, physics, layers, saves. |
| [`internal/`](./internal/README.md) | Us. How we measure, what we already tried, and the project journal. |

The npm package does not ship this folder. `npm i @weed.js/engine` is `dist/` and the types. These files stay on GitHub.
