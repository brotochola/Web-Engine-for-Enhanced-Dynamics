- [x] **DX-FFBIN** (engine, feature) — asked 2026-11-11 by the owner, built the same day on `dx/flowfield-bin` (`8d71beac`, the converter `cb2eeb7d`, all at once `2522d5d0`, the demo `26d88616`). **Static flowfields in a binary file the browser opens itself.** `static assets.flowfields` takes WeedJS's binary format as well as JSON: a 24-byte header ("WEFF", version 1, compression, width and height in cells, cell size as f64) and the cells as NavGrid holds them, x, y as Int8 per cell, gzipped with `CompressionStream` and opened with `DecompressionStream`, so no server compression is needed and nothing is parsed. The format comes from the first bytes; JSON loads as before, quantized the same. The demo's barrio: 3.7 MB of JSON, 116 KB binary, every cell equal; the main thread's time to turn the bytes into cells in Chromium 18 to 21 ms → 5 to 6 ms the first time. The fields are fetched all at once now. The barrio editor exports either (its knob `ffBinario`, in the game's repo), `scripts/flowfieldToBinary.mjs` converts JSON, and the guide's "Static flowfields" documents both formats.
- [ ] **DX-VOLLIGHTS** (engine, feature, design) — asked 2026-11-11 by the owner (do Sun Street's raycasted lamps see its volumes? They do not). **Lamps and headlights cast a `VolumeShadowCaster`'s shadow**, from the base to `p + (p − l) · h / (H − h)` with `H` the bulb's `sourceHeight`, fading with the lamp's falloff, and never on the object's own picture. One opt-in per volume (`castsLights`, off by default), the existing shadow-casting lights, no new layer or entity. Basic lighting draws it into `shadowRT` like the sprite stamps; raycasted lighting cuts each lamp's fan with a mask, four lights a pass, with the volumes' own pictures cleared from it. Sun Street could then drop `LightOccluder` from its houses and cars, whose wedge darkens the wall that faces the lamp and never ends. The plan, with the picture case by case, the API, phases and eight decisions: [`DX_VOLLIGHTS_DESIGN.md`](./DX_VOLLIGHTS_DESIGN.md). Not built.
